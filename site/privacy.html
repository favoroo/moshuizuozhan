PRIVACY POLICY

隐私政策

生效日期：2026 年 11 月 2 日 · 版本 1.0

《墨水大作战》（英文名 InkTurf，以下简称“本游戏”）由 HQ Games Studio（以下简称“我们”）开发并发布。我们重视你的隐私，本政策说明本游戏会处理哪些信息、为什么处理、以及你可以如何控制。

一、我们处理的信息

本游戏是单机 4v4 涂地对战游戏，不提供账号系统，不需要登录，不收集手机号、位置、通讯录、相册、麦克风或摄像头信息。

  • 本地设置：音量、画质、触控布局、按键映射、隐私同意状态等仅保存在你的设备本地（Unity PlayerPrefs），不会上传到我们的服务器。
  • 检查更新：只有当你主动点击“检查更新”时，本游戏才会访问 Gitee / GitHub 的公开 Release 接口获取版本信息。请求会携带常规网络信息（如 IP 地址、User-Agent、请求时间），这些信息由对应代码托管平台按其隐私政策处理，我们仅用于判断版本与提供下载地址，不用于用户画像或广告。
  • 分发平台：当你通过 TapTap 下载、安装或启动本游戏时，TapTap 平台可能按其公布的隐私政策处理相关信息。本游戏未接入 TapTap 登录、广告、统计或支付 SDK，不会从 TapTap 获取你的账号信息。

二、权限说明

  • 网络权限（INTERNET）：用于你主动触发的版本检查与下载页跳转。

本游戏不申请读取电话状态、位置、通讯录、相册、麦克风、摄像头、应用列表或安装应用等高危权限。更新安装由 TapTap 商店或浏览器完成。

三、第三方组件

本游戏使用 Unity 引擎与 AndroidX 基础库运行。我们未启用 Unity Analytics、Unity Ads、Unity IAP 或任何第三方广告、统计、推送、支付 SDK。Unity 引擎与 AndroidX 本身不用于收集你的个人信息。

四、信息的存储与删除

本游戏没有账号系统，也不在我们控制的服务器上保存你的个人信息。本地设置与同意状态保存在你的设备上，你可以通过系统“清除应用数据”或卸载本游戏删除。删除后再次启动会重新显示隐私同意弹窗。

五、未成年人保护

本游戏无内购、无账号、无社交聊天功能。未成年人应在监护人指导下阅读本政策并使用本游戏；如监护人不同意，请停止使用并卸载本游戏。

六、你的权利

你可以在首次启动弹窗或暂停菜单中查看本政策。你可以随时撤回同意：在系统设置中清除本游戏的应用数据，或卸载本游戏。撤回同意后，本游戏将不再发起检查更新请求；再次启动时会重新询问是否同意。

七、政策更新

如果本政策发生实质变化，我们会更新版本号，并在游戏内重新提示你阅读并同意。更新后的政策自标注的生效日期起生效。

八、联系我们

如对本政策有任何疑问、意见或投诉，可通过以下方式联系：

  • GitHub Issues：github.com/favoroo/moshuizuozhan/issues
  • TapTap 平台内搜索《墨水大作战》并进入游戏页面留言。

本政策自 2026 年 11 月 2 日起生效。
