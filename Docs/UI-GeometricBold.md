# UI 规范 · 几何大胆风（Geometric Bold）

> 本文档是 P1 项目 UI 的**唯一风格规范**（取代旧 `UI-ComicStyle.md`）。
> 改任何 UI 前必读；自检清单在文末，交付前逐条过。

## 设计语言

受包豪斯 / 构成主义影响、并对标 t-1 新野兽派（Neo-Brutalism）的**纯色几何**语言：
大色块、规则形状、超大粗体字、硬偏移阴影、不对称构图。
**2026-11 圆角化**：全站从直角改为圆角语言（圆形优先 → 胶囊 → 圆角矩形）。

- **形状优先**：圆角矩形、正圆、胶囊是全部装饰词汇（真直角只留给 1~2px 细线与全屏特效层）
- **大胆对比**：黑白为底，强调色只做 1~2 种；整页界面用深色舞台底托亮色块
- **数字即设计**：比分、百分比、倒计时用超大字号当作视觉主体
- **立体只靠硬影**：唯一允许的立体感是「零模糊硬偏移阴影」（同形状纯色偏移底板，圆角自动跟随）
- **零模糊**：无渐变、无柔光、无 blur / spread / 半透明阴影、无网点

## 立体感：零模糊硬偏移阴影（t-1 解禁）

旧版规范把阴影整体禁掉了；t-1 只解禁**一种**：

- 画法 = 把整块形状**平移复制一份纯色底板**垫在填充层下面
  （`UIInkShapeGraphic.HardShadow = true` + `ShadowOffset`）；
- 颜色 = **不透明纯墨黑**（`hardShadowColor`，绘制时 alpha 强制 1）；
- **禁止** blur / spread / 半透明 / 渐变投影 / 多层柔光，也禁止只给部分边的斜切投影；
- uGUI 的 y 向上，因此「阴影在右下」= **正 x / 负 y**；
- 偏移档位只有下表这几档，**禁止在界面代码里现编数值**
  （常量见 `ComicStyle.Shadow*`，主题入口 `UIThemeSO.GetHardShadowOffset()`）。

| 档位 | 偏移 (x, y) | 用途 |
|---|---|---|
| 色签 Tag | `(2, -3)` | 小徽章、状态标签、图标角标 |
| 按钮 Button | `(3, -4)` | 所有可点按钮的常态 |
| 按钮悬停 ButtonHover | `(5, -6)` | hover 时硬切，阴影变大，不补间 |
| 按钮按下 ButtonPressed | `(0, 0)` | 贴回底板；内容同时向原阴影方向位移同样像素 |
| 面板 Panel | `(4, -5)` | 卡片、面板、列表容器 |
| Hero 色块 Hero | `(6, -7)` | 首页 Hero 标题块、结算大判定块 |
| 弹窗 Dialog | `(8, -9)` | 模态弹窗主面板 |

- **按钮硬影怎么开**：`theme.ApplyHardShadow(shape, UIHardShadowLevel.Button)`；
  走 `UIJellyButton` 的按钮可直接 `jelly.EnableThemeHardShadow()`（连带 hover/按下物理）。
- **面板硬影怎么开**：`theme.ApplyHardShadow(panelShape, UIHardShadowLevel.Panel)`；
  用 `UIInkCardStyle` 的卡片把 `shadowOffset` 设为面板档后，`ApplyStyle` 会自动启用硬影。
- 阴影会画到 Rect 之外，**布局要给右下留 8~10px 余量**；父级有 `RectMask2D` 时阴影会被裁掉，
  不要在滚动视口内部给卡片加硬影。

## 深色舞台底（整页界面）

主菜单、战前选枪、结算等**整页界面**统一用深色舞台底，不再整页铺白：

- 底色 = 墨黑（`Ink #141414`）或深墨（`#0B0B0B`），首页/结算允许略偏暖的极深墨黑
  `#12100E`（`MatchFlowUI.StageInk`，与纯黑硬影形成 1~2 级明度差，硬影才不糊进背景）；
  内容层叠高饱和大色块（纸白卡片 / 队伍色 / 主行动色）；
- 舞台上的背景装饰（旋转方块 / 大圆 / 星点）一律 **alpha 0.10~0.18** 的低透明几何，
  不做循环动画；它们只负责构图张力，不能变成第二个视觉焦点；
- 舞台底上**不放大面积高饱和色**——高饱和只给主角块，保证视觉落点唯一；
- 战斗中 HUD 保持**透明浮层**：不做整底、不加全屏黑布，避免遮挡涂地信息。

## 卡片身份色带

卡片从「整面亮色」改为「纸白 + 顶部功能色带」，身份色只占一条，信息层保持可读：

- 卡片 = **纸白圆角底 + 3px 墨黑框 + 硬影（面板档 4,-5，同形状跟随圆角） + 顶部 5px 功能色带**；
- 色带颜色 = 该卡片的身份色（队伍橙/蓝、主行动色、语义色），**不再整面铺亮色**；
- **圆角化**：色带横向内缩到卡片圆角的直线段内（内缩量 = 圆角半径 + 边框），并改成**胶囊短划**——
  顶角是圆的，直角色带会戳出卡片轮廓；
- 卡内标题墨黑、正文墨黑或次级灰；色带不承载文字；
- 队伍色卡片（战况条等）保留整面色块，属于「状态色块」而非「信息卡片」，不受此条约束。

## Token（代码实现见 `Scripts/UI/Core/ComicStyle.cs`）

### 色板收敛（单屏高饱和功能色 ≤4 种）

| 层级 | 角色 | 值 | 用途 |
|---|---|---|---|
| 基础 | `Ink` | `#141414` | 文字、边框、深色块、舞台底 |
| 基础 | `Paper` | `#FFFFFF` | 卡片/浅色块主底 |
| 基础 | `PaperAlt` | `#F0F0F0` | 次级区块（仅列表行/内嵌） |
| 行动 | `Action` | `#FFD400` | 主行动色：开赛 CTA、主按钮强调 |
| 队伍 | 橙 / 蓝 | `#FF7314` / `#296BFF` | **不改**，涂地玩法可读性依赖 |
| 语义 | 金 `#FFD400` | 奖励 / 就绪 / 满能 | 与主行动色同源，不再另立第三种黄 |
| 语义 | 绿 `#1FC94F` | 增益 / 生命 | 生命条、治疗/加速状态 |
| 语义 | 红 `#FF2E2E` | 危险 / 代价 | 敌墨、扣血、销毁性操作 |
| 语义 | 灰 `#6F6F6F` | 禁用 / 未就绪 | 不可点、冷却中文字与边框 |

- 单屏同时出现的高饱和**功能色**（不含墨黑/纸白/灰）≤ 4 种；
- 主行动色与「金=奖励」共用同一黄，**不要新增第二种黄色**；
- 移动端动作键从「5 色实底」改为 **墨黑半透明底 + 功能色 4px 描边 + 功能色图标**，
  功能色只出现在描边和图标上，按下去才允许整块翻成功能色。

### 度量

| Token | 值 | 说明 |
|---|---|---|
| `BorderThin / Border / BorderHeavy` | 3 / 4 / 6 px | 边框全部纯色实线 |
| `CornerPanel / CornerChip` | **32 / 12 px** | 圆角半径上限/下限 |

| `CornerFor(w, h)` | clamp(短边×0.30, 12, 32) | **唯一半径来源**：`RoundedRect` 半径为 0 时构建期自动取用 |

| `CornerBubble` | 999 | 正圆/胶囊（`Pill` 形状专用，头像、Tag、进度条） |
| `Shadow*` | 见「硬偏移阴影」档位表 | 唯一允许的立体感；不透明纯墨黑、零模糊、**同形状自动跟随圆角** |

| HUD 英雄数字 | **40** | 大招百分比、关键读数 |

### 字体（2026-11-01 起：全站唯一家族 MiSans）

| 角色 | TMP 资产 | 源 TTF | 采样 | `boldStyle` |
|---|---|---|---|---|
| 正文（含拉丁/数字/汉字） | `MiSans-Semibold SDF` | `MiSans-Semibold.ttf`（650） | **64pt / padding 6** | **0.25**（轻加粗） |
| 标题 / 强调 / 大数字 | `MiSans-Heavy SDF` | `MiSans-Heavy.ttf`（900） | **96pt / padding 8** | **0**（不再叠加膨胀） |

- **不再有第二个字体家族**：旧的 TitanOne（拉丁标题）/ Rubik-Bold（拉丁正文）已退役，资产留档但不再被主题、
  代码或 fallback 引用。MiSans 自带完整拉丁字形（95/95），中英混排的笔画粗细、行高、字距终于一致。
- **禁止把 `boldStyle` 调回 0.75**（TMP 默认值）：那是 shader 里的字形膨胀，叠在 650/900 的真字重上会
  让密笔汉字（「墨」这类）在小字号糊成黑块、大字号涨成实心。需要更重请换 Heavy 资产，而不是加膨胀。
- **字重靠资产分工，不靠伪粗体**：标题/大数字用 Heavy；正文默认就是 Semibold，`FontStyles.Bold` 只表示
  「比正文略重一档」的强调（0.25）。
- **预烘字集账本**（`tools/font_charset.py` → `tools/font_charset.txt` / `font_baseline.txt` /
  `font_exempt_chars.txt`）：正文资产预烘源码字面量全集（≈1270 字 / 8 张 1024² 图集），标题资产只烘
  ASCII + 项目符号（≈163 字 / 3 张）。改文案后必须重跑脚本并提交账本；`FontCoverageTests` 会拦下漏账。
- **豁免字（MiSans 没有字形）只许进注释与编辑器日志，不许上屏**：真机走系统回退字体时整层 UI 会当帧重排。
  缺图标就画图形或用 MiSans 有的符号，不要拿 `⚙ ⚠ ✅ ❌` 这类字符顶替。
- 拉丁大标题仍 `UpperCase + 字距收紧`；数字不再单独换字体（旧版数字走 TitanOne 的「漫画味」已取消）。

### 动效（硬切 + Cubic-Out，无循环脉冲）

| 场景 | 参数 |
|---|---|
| Hover | 颜色硬切（黑↔强调色互换）或 `scale 1.05`；**阴影 (3,-4)→(5,-6) 硬切，不补间** |
| Press | **0ms 硬切** `scale 0.97`；硬影瞬时归零；内容向阴影方向位移同样像素 |
| Release | **0.1s Cubic-Out** 回弹到 1.0，内容归位、阴影恢复（不 bounce/不过冲） |
| 入场 | **0.22s Back-Out**（轻微过冲后收稳）+ alpha；多张卡片按 **0.05s/张** 错峰 pop-in |
| 其它交互 | ≤100ms，linear 硬切 |
| 禁止 | 弹簧 / elastic / 无限呼吸 / 循环脉冲 / 摆动（PlayWobble）/ 透明度慢拖尾 |
| 例外 | 功能性告警闪烁（低墨、冷却完成）允许有限次数闪烁，但不得常驻循环 |

### 触控 / 设置控件尺寸下限

| 场景 | 下限 |
|---|---|
| 游戏内触控键（开火/跳跃/手雷/大招/摇杆） | **≥132×132 UI px** @1920×1080（物理 ≥9mm） |
| 设置项 / 编辑器类按钮（键位自定义、布局、列表行） | 高 **≥64px**、字号 **≥20** |
| 图标显示尺寸 | **≥24px**（小于 24 的图标直接不显示，别糊成噪点） |
| 卡片顶色带 | 高 **5px**（不承载文字） |

- **按键布局编辑器背板**：进入编辑后铺全屏**不透明**深墨舞台底（`MatchFlowUI.StageInk` #12100E），
  节点必须在触屏按键与编辑面板**之下**（触屏画布第一个兄弟位）。禁止用半透明遮罩：
  首页的纸白卡片会透出来、按键也会被再压暗一层；编辑期同时收起左上「键位」快捷入口。

## 组件规则（圆角语言）

- **面板**：圆角矩形（`RoundedRect`，半径 0 = `ComicStyle.CornerFor` 自适应）+ `Border` 实线边框 +
  纯色底（纸白底墨边 或 墨底白字）+ **面板硬影 (4,-5)**（同形状自动跟随圆角）；
  分层仍以**色块**为主，硬影只做“离地”提示
- **按钮**：圆角矩形 + `墨底白字 / 纸白底墨字 粗体` + 按钮硬影 (3,-4)；hover 硬切成强调底并 **阴影硬切到 (5,-6)**；
  active 0ms 硬切 `scale 0.97` + 阴影归零 + 内容位移，松开 0.1s Cubic-Out 回弹；
  次级按钮 `白底墨字墨边 + 3px 边`
- **卡片**：纸白圆角底 + 3px 墨框 + 面板硬影 + 顶部 5px 胶囊身份色带（详见「卡片身份色带」）
- **圆形元素**（头像 / 图标底 / ≤44px 方块徽章 / 复选框 / 关闭键）：`Pill` 形状（方形 rect 即正圆）+ 纯色，边框 4px
- **条签/徽章/进度条**（Tag、角签、ready hint、倒计时徽标、加载块）：`Pill` 胶囊；文字居中占中间带，宽度自适应
- **进度条/滑轨**：轨道与填充一律**胶囊**——mesh 走 `UIInkShapeGraphic.Pill`，
  `Image` 填充走 `UIPillImage`（自动按纵横比取胶囊精灵，`fillAmount` 逻辑不变）或 `UIFlatSprite.MakePill`；
  描边环（Frame）同步改 `Pill`，三者轮廓一致
- **细线**（1~2px 分隔线、阈值竖线刻度、标题分隔线、全屏擦除边）：保持真直角（`SharpRect`），圆角会被钳掉无意义
- **装饰**：星点/小方块改正圆点（`Pill`）；45° 旋转方块改圆角菱形（`RoundedRect` 旋转）；单屏 1~2 个强调色
- **图标**：走 `UIIconLibrary.Get()`，取不到必须隐藏 Image（禁止白方块）；显示尺寸 <24px 时不显示
- **运行时建底板**：唯一入口 `UIInkShapeGraphic.CreateChildBackground(parent)`；
  已有 Image 的物体禁止 `AddComponent<UIInkShapeGraphic>()`（静默返回 null）
- 运行时创建任何 Graphic 必须同时有 `CanvasRenderer`（`new GameObject(name, typeof(RectTransform), typeof(CanvasRenderer), typeof(T))`）
- **按钮硬影/按压位移入口**：`UIJellyButton.EnableThemeHardShadow()`（推荐）或
  `theme.ApplyHardShadow(shape, UIHardShadowLevel.Button)`；不开硬影的按钮保持原样（零行为变化）

## HUD 底部状态区（双横条 · 2026-11 四轮）

战斗 HUD 底部是**两条横条**（大招 / 生命）：每行 344×34（桌面）/ 379×38（移动端），
两行行距 10 / 11，整组 344×78 / 379×87，底边居中（y = 54 / 46）。条内只有**一个身份徽章 + 一条横条**，
右端不挂任何小件（二轮试过的「Q」键帽与生命读数芯片已全部删除，用户判定为"太丑"）。
墨水量不在底部（P42-E 起看准星旁竖罐）。

```
 ◎ ⬤ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬   ← 大招：墨黑徽章 + 黄图标 / 墨黑轨道 + 行动黄填充
 ⬤ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬   ← 生命：绿底墨十字徽章 / 墨黑轨道 + 语义绿填充
```

| 行 | 左端身份徽章 | 轨道（桌面 / 移动） |
|---|---|---|
| 大招 | 34 正圆（墨底 + 3px 墨边 + 色签硬影）+ 28px 行动黄技能图标 | 300×18 / 330×20 墨黑胶囊（色签硬影） |
| 生命 | 34 正圆（语义绿底 + 墨边 + 硬影）+ 28px 墨色十字（`glyph_plus`） | 同规格墨黑胶囊 |

- 轨道内是**内缩 3px 的胶囊填充**（`UIPillImage` + `Image.Type.Filled / Horizontal / Left`），
  轨道右沿 = 行右沿（组宽 = 徽章 + 间隙 + 轨道），条内不留右槽。
- **身份靠左端徽章**（黄技能图标 = 大招 / 绿十字 = 生命）、**进度靠条长**；
  行内所有尺寸/位置只由 `HudSpecialGaugeFactory.ApplyBarRowMetrics()` 写，禁止各写一套。
- 移动端整组放大到 379×87（行高 38、轨道 330×20、徽章 38、图标 32），**不许比桌面小**。
- 大招满能**只换左端徽章的状态**：墨底黄图标 ↔ **黄底墨图标**（3px 墨边常驻），
  并在徽章外露出 **`ReadyRing`**（留 2px 缝的 4px 黄环，填充透明，桌面外扩 12px / 移动端 14px）。
  条身颜色、长度都不变；**不做条身闪烁、不做爆闪、不做 Pop/Punch**——
  用户判定过闪条/爆闪是"乱七八糟"，明确要求只让图标变一下。
  陷阱：反色必须**底色与图标同时翻**——只翻底色会让黄图标消失在黄底上。
- **小尺寸形状必须抗锯齿**：徽章 / 轨道网格开 `UIInkShapeGraphic.EdgeFeather`（外沿 alpha 羽化），
  胶囊填充贴图开 mip + 三线性，图标贴图开 mip（`MediaImportPostprocessor` 的 `UiIconSprite`）——
  UI 网格没有 MSAA、128px 图标硬缩到 28px，是「锯齿/发毛」的两个根因。
- 除了低墨 / 低血这种功能性告警，HUD 不做任何循环闪。
- 生命告警（<30% 或踩敌墨）= 填充与徽章翻红 + **填充**在红 ↔ 纸白之间 2.2Hz 交替闪（脱险即停）；
  条长始终等于剩余血量，只换色不换长度。掉血整行一记 Punch（0.25s 节流，回血/复活不触发）。
- 填充一律 `UIPillImage`（按条宽自动换胶囊精灵）；横条**不再使用** `UIArcRingGraphic`。
- 大招**不显示百分比、不显示数字**（条长本身就是读数）；生命也不显示数字（三条信息只留条长与告警闪）。
  不要再往条内塞按键提示 / 读数 / 图标——底部只允许「徽章 + 横条」这两种构件。
- 战斗 HUD 底部**不显示按键提示、也不显示状态小字**：只有**阵亡复活倒计时**一行，锚在横条组上方 26px。
  键鼠 / 触控键位走暂停菜单右栏「操作说明」卡。
- 旧场景节点 `BottomStatusPanel / ComicBubble / PanelDivider` 只留作不可见容器（禁绘制、禁射线），
  `InkBarBg / SpecialBarBg / SpecialStateText` 失活；`HealthBarBg / HealthBarFill` 绑定节点**不得删除**——
  `HealthBarFill` 现在是**禁绘制的数据载体**（`fillAmount` 仍被写入），实际绘制由同行 `BarTrack/BarFill` 承担。
- 横条组根节点与旧面板容器都用**底边锚定**（anchor/pivot `(0.5, 0)`），由
  `HudController.ApplyBottomPanelLayout()` + `HudSpecialGaugeFactory.ApplyStatusCardsLayout()` 统一写几何；
  禁止各写一套 anchoredPosition（会错位）。
- 手雷冷却只在**准星下方**显示一条 `BOMB ███░░ 5.4s` 徽标（冷却结束短促 READY）；
  移动端同时把手雷按钮标签切成倒计时秒数。

## 绝对禁止

- ❌ 渐变色 / 柔光 / 玻璃拟态
- ❌ **模糊阴影**：blur / spread / 半透明阴影 / 渐变投影 / 多层柔光（唯一允许的是零模糊硬偏移底板，见上）
- ❌ 半调网点 / 动作线 / 对话气泡尾巴（漫画语言，已废弃）
- ❌ **全直角面板/按钮**（2026-11 圆角化起废弃旧直角规则）：面板、卡片、按钮一律圆角矩形；
  真直角只允许 1~2px 细线、全屏特效层与 `SharpRect` 兼容场景
- ❌ **界面代码现编圆角数值**：半径只走 `ComicStyle.CornerFor`（自适应）或 `Pill`（全圆），
  正圆/胶囊以外不许手写具体半径
- ❌ 墨滴 wobble 有机边缘
- ❌ 弹簧 / elastic / 无限呼吸 / 循环脉冲 / 摆动动画（功能性告警闪烁除外）
- ❌ 交互动画 >100ms（入场 pop-in 与松开回弹除外：入场 0.22s、回弹 0.1s）
- ❌ 低对比配色：正文对比度必须 ≥ 4.5（`ComicStyle.ContrastRatio` 自检）
- ❌ 移动端字号 < 桌面字号；正文 < 18（移动端 < 20）；**任何可读文字 13~16px**
- ❌ 触控层用 5 色实底（改为墨黑半透明底 + 功能色 4px 描边 + 功能色图标）
- ❌ 对称居中堆叠的"常规后台"布局（标题+列表居中排列）：用色块错位、超大字、左右分栏制造张力
- ❌ 旧 API `UnityEngine.Input.GetKeyDown`（项目只启用新 Input System）

## 形状基元（`UIInkShapeGraphic`）

| Shape | 用途 |
|---|---|
| `RoundedRect` | **默认**：圆角矩形（面板、按钮、卡片、色块）；半径 0 = `CornerFor` 按短边自适应，硬影同形状跟随 |
| `Pill` | 全圆角胶囊：方形 rect 即正圆、长条即胶囊（Tag、徽章、进度条、圆点） |
| `Blob` | 仅作**正圆/椭圆**用（wobble 已归零）：头像、装饰圆 |
| `SharpRect` | 真直角（兼容保留）：1~2px 细线、全屏特效层 |
| `SpeechBubble` | 兼容保留，新界面禁用 |

快捷入口：`ApplyComic(fill)` 是几何风默认（圆角矩形自适应半径、无网点、无边光、**默认无硬影**）。
要硬影不要靠它——用 `theme.ApplyHardShadow(graphic, level)` 显式开档，保证偏移只有规范里的那几档。
