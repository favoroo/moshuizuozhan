# UI 规范 · 几何大胆风（Geometric Bold）

> 本文档是 P1 项目 UI 的**唯一风格规范**（取代旧 `UI-ComicStyle.md`）。
> 改任何 UI 前必读；自检清单在文末，交付前逐条过。

## 设计语言

受包豪斯 / 构成主义影响、并对标 t-1 新野兽派（Neo-Brutalism）的**纯色几何**语言：
大色块、规则形状、超大粗体字、硬偏移阴影、不对称构图。

- **形状优先**：矩形（直角）、正圆、三角是全部装饰词汇
- **大胆对比**：黑白为底，强调色只做 1~2 种；整页界面用深色舞台底托亮色块
- **数字即设计**：比分、百分比、倒计时用超大字号当作视觉主体
- **立体只靠硬影**：唯一允许的立体感是「零模糊硬偏移阴影」（同形状纯色偏移底板）
- **零模糊**：无渐变、无柔光、无 blur / spread / 半透明阴影、无网点

## 立体感：零模糊硬偏移阴影（t-1 解禁）

旧版规范把阴影整体禁掉了；t-1 只解禁**一种**：

- 画法 = 把整块形状**平移复制一份纯色底板**垫在填充层下面
  （`UIInkShapeGraphic.HardShadow = true` + `ShadowOffset`）；
- 颜色 = **不透明纯墨黑**（`hardShadowColor`，绘制时 alpha 强制 1）；
- **禁止** blur / spread / 半透明 / 渐变投影 / 多层柔光，也禁止只给部分边的斜切投影；
- uGUI 的 y 向上，因此「阴影在右下」= **正 x / 负 y**；
- 偏移档位只有下表这几档，**禁止在界面代码里现编数值**
  （常量见 `ComicStyle.Shadow*`，主题入口 `UIThemeSO.GetHardShadowOffset()`）。

| 档位 | 偏移 (x, y) | 用途 |
|---|---|---|
| 色签 Tag | `(2, -3)` | 小徽章、状态标签、图标角标 |
| 按钮 Button | `(3, -4)` | 所有可点按钮的常态 |
| 按钮悬停 ButtonHover | `(5, -6)` | hover 时硬切，阴影变大，不补间 |
| 按钮按下 ButtonPressed | `(0, 0)` | 贴回底板；内容同时向原阴影方向位移同样像素 |
| 面板 Panel | `(4, -5)` | 卡片、面板、列表容器 |
| Hero 色块 Hero | `(6, -7)` | 首页 Hero 标题块、结算大判定块 |
| 弹窗 Dialog | `(8, -9)` | 模态弹窗主面板 |

- **按钮硬影怎么开**：`theme.ApplyHardShadow(shape, UIHardShadowLevel.Button)`；
  走 `UIJellyButton` 的按钮可直接 `jelly.EnableThemeHardShadow()`（连带 hover/按下物理）。
- **面板硬影怎么开**：`theme.ApplyHardShadow(panelShape, UIHardShadowLevel.Panel)`；
  用 `UIInkCardStyle` 的卡片把 `shadowOffset` 设为面板档后，`ApplyStyle` 会自动启用硬影。
- 阴影会画到 Rect 之外，**布局要给右下留 8~10px 余量**；父级有 `RectMask2D` 时阴影会被裁掉，
  不要在滚动视口内部给卡片加硬影。

## 深色舞台底（整页界面）

主菜单、战前选枪、结算等**整页界面**统一用深色舞台底，不再整页铺白：

- 底色 = 墨黑（`Ink #141414`）或深墨（`#0B0B0B`），首页/结算允许略偏暖的极深墨黑
  `#12100E`（`MatchFlowUI.StageInk`，与纯黑硬影形成 1~2 级明度差，硬影才不糊进背景）；
  内容层叠高饱和大色块（纸白卡片 / 队伍色 / 主行动色）；
- 舞台上的背景装饰（旋转方块 / 大圆 / 星点）一律 **alpha 0.10~0.18** 的低透明几何，
  不做循环动画；它们只负责构图张力，不能变成第二个视觉焦点；
- 舞台底上**不放大面积高饱和色**——高饱和只给主角块，保证视觉落点唯一；
- 战斗中 HUD 保持**透明浮层**：不做整底、不加全屏黑布，避免遮挡涂地信息。

## 卡片身份色带

卡片从「整面亮色」改为「纸白 + 顶部功能色带」，身份色只占一条，信息层保持可读：

- 卡片 = **纸白底 + 3px 墨黑框 + 硬影（面板档 4,-5） + 顶部 5px 功能色带**；
- 色带颜色 = 该卡片的身份色（队伍橙/蓝、主行动色、语义色），**不再整面铺亮色**；
- 卡内标题墨黑、正文墨黑或次级灰；色带不承载文字；
- 队伍色卡片（战况条等）保留整面色块，属于「状态色块」而非「信息卡片」，不受此条约束。

## Token（代码实现见 `Scripts/UI/Core/ComicStyle.cs`）

### 色板收敛（单屏高饱和功能色 ≤4 种）

| 层级 | 角色 | 值 | 用途 |
|---|---|---|---|
| 基础 | `Ink` | `#141414` | 文字、边框、深色块、舞台底 |
| 基础 | `Paper` | `#FFFFFF` | 卡片/浅色块主底 |
| 基础 | `PaperAlt` | `#F0F0F0` | 次级区块（仅列表行/内嵌） |
| 行动 | `Action` | `#FFD400` | 主行动色：开赛 CTA、主按钮强调 |
| 队伍 | 橙 / 蓝 | `#FF7314` / `#296BFF` | **不改**，涂地玩法可读性依赖 |
| 语义 | 金 `#FFD400` | 奖励 / 就绪 / 满能 | 与主行动色同源，不再另立第三种黄 |
| 语义 | 绿 `#1FC94F` | 增益 / 生命 | 生命条、治疗/加速状态 |
| 语义 | 红 `#FF2E2E` | 危险 / 代价 | 敌墨、扣血、销毁性操作 |
| 语义 | 灰 `#6F6F6F` | 禁用 / 未就绪 | 不可点、冷却中文字与边框 |

- 单屏同时出现的高饱和**功能色**（不含墨黑/纸白/灰）≤ 4 种；
- 主行动色与「金=奖励」共用同一黄，**不要新增第二种黄色**；
- 移动端动作键从「5 色实底」改为 **墨黑半透明底 + 功能色 4px 描边 + 功能色图标**，
  功能色只出现在描边和图标上，按下去才允许整块翻成功能色。

### 度量

| Token | 值 | 说明 |
|---|---|---|
| `BorderThin / Border / BorderHeavy` | 3 / 4 / 6 px | 边框全部纯色实线 |
| `CornerSharp` | **0** | 面板/按钮一律直角 |
| `CornerBubble` | 999 | 圆形/胶囊（头像、Tag）专用 |
| `Shadow*` | 见「硬偏移阴影」档位表 | 唯一允许的立体感；不透明纯墨黑、零模糊 |
| `ShadowOffset / HoverShadowOffset`（旧常量） | `0` | 仅为旧调用方兼容保留，新代码用 `Shadow*` 档位 |
| 半调网点 | **禁用** | `HalftoneAlpha = 0` 全局关闭 |

### 字号阶梯（桌面 @1920×1080，移动端 ×1.28 见下）

| 层级 | 值 | 用途 |
|---|---|---|
| Hero 标题 | **120** | 主菜单标题、结算 VICTORY |
| 菜单 CTA | **46** | 开赛按钮、弹窗主按钮 |
| 计时器 | **72~76** | 中央倒计时（比分时钟） |
| 比分 | **44** | 双方比分数字 |
| HUD 英雄数字 | **40** | 大招百分比、关键读数 |
| HUD 读数 | **28~32** | 墨水/生命百分比、武器名 |
| 击杀卡 | **24** | 击杀播报主文、卡片正文 |
| HUD 标签 | **18~20** | 辅助说明、键位提示 |
| 下限 | **18** | **禁止 13~16px 出现在任何可读文字**（移动端 ≥20） |

- **移动端整体放大一档**：统一走 `UITypography.Font(baseSize)`，移动端 ×1.28，最小 20；
  **禁止移动端比桌面小**（历史 bug：计时器 80→68、墨水罐 22→14）。
- 拉丁大标题 `UpperCase + 字距收紧`；中文用 MiSans-Heavy（标题）/ MiSans-Semibold（正文）。

### 动效（硬切 + Cubic-Out，无循环脉冲）

| 场景 | 参数 |
|---|---|
| Hover | 颜色硬切（黑↔强调色互换）或 `scale 1.05`；**阴影 (3,-4)→(5,-6) 硬切，不补间** |
| Press | **0ms 硬切** `scale 0.97`；硬影瞬时归零；内容向阴影方向位移同样像素 |
| Release | **0.1s Cubic-Out** 回弹到 1.0，内容归位、阴影恢复（不 bounce/不过冲） |
| 入场 | **0.22s Back-Out**（轻微过冲后收稳）+ alpha；多张卡片按 **0.05s/张** 错峰 pop-in |
| 其它交互 | ≤100ms，linear 硬切 |
| 禁止 | 弹簧 / elastic / 无限呼吸 / 循环脉冲 / 摆动（PlayWobble）/ 透明度慢拖尾 |
| 例外 | 功能性告警闪烁（低墨、冷却完成）允许有限次数闪烁，但不得常驻循环 |

### 触控 / 设置控件尺寸下限

| 场景 | 下限 |
|---|---|
| 游戏内触控键（开火/跳跃/手雷/大招/摇杆） | **≥132×132 UI px** @1920×1080（物理 ≥9mm） |
| 设置项 / 编辑器类按钮（键位自定义、布局、列表行） | 高 **≥64px**、字号 **≥20** |
| 图标显示尺寸 | **≥24px**（小于 24 的图标直接不显示，别糊成噪点） |
| 卡片顶色带 | 高 **5px**（不承载文字） |

## 组件规则

- **面板**：直角 + `Border` 实线边框 + 纯色底（纸白底墨边 或 墨底白字）+ **面板硬影 (4,-5)**；
  分层仍以**色块**为主，硬影只做“离地”提示
- **按钮**：`墨底白字 / 纸白底墨字 粗体` + 按钮硬影 (3,-4)；hover 硬切成强调底并 **阴影硬切到 (5,-6)**；
  active 0ms 硬切 `scale 0.97` + 阴影归零 + 内容位移，松开 0.1s Cubic-Out 回弹；
  次级按钮 `白底墨字墨边 + 3px 边`
- **卡片**：纸白底 + 3px 墨框 + 面板硬影 + 顶部 5px 身份色带（详见「卡片身份色带」）
- **圆形元素**（头像 / 图标底）：正圆 + 纯色，边框 4px
- **装饰**：旋转 15°/45° 的方块、圆、三角，绝对定位制造重叠与不对称；单屏 1~2 个强调色
- **图标**：走 `UIIconLibrary.Get()`，取不到必须隐藏 Image（禁止白方块）；显示尺寸 <24px 时不显示
- **运行时建底板**：唯一入口 `UIInkShapeGraphic.CreateChildBackground(parent)`；
  已有 Image 的物体禁止 `AddComponent<UIInkShapeGraphic>()`（静默返回 null）
- 运行时创建任何 Graphic 必须同时有 `CanvasRenderer`（`new GameObject(name, typeof(RectTransform), typeof(CanvasRenderer), typeof(T))`）
- **按钮硬影/按压位移入口**：`UIJellyButton.EnableThemeHardShadow()`（推荐）或
  `theme.ApplyHardShadow(shape, UIHardShadowLevel.Button)`；不开硬影的按钮保持原样（零行为变化）

## HUD 底部状态区（三卡并排 · 2026-11 t-1 收尾波次）

战斗 HUD 底部是**三张并排的独立状态卡**（墨水 / 大招 / 生命），不再有单块墨黑信息条。
每张卡 = 纸白底 + 3px 墨框 + 面板硬影 `(4,-5)` + 顶部 5px 身份色带（与首页 2×2 卡同一语言）。

| 卡 | 尺寸（桌面 / 移动） | 身份色带 | 满能/告警硬切 |
|---|---|---|---|
| 墨水 | 332×88 / 332×72 | 队伍色 | 低墨：轨道/色带翻红 |
| 大招 | 332×88 / 332×72 | 主行动黄 | 满能：整卡翻黄 + 墨字 + 「Q 释放」小签 |
| 生命 | 380×88 / 380×72 | 语义绿 | 低血（<30%）/ 踩敌墨：色带翻红 |

- 三卡底部居中，卡间距 16（移动端 12），卡区根节点底边 y = 56（移动端 46），总宽 1076；
  必须落在左右触控键（约各 200px）之外。
- 卡内布局：12 内边距 + 44×44 墨底徽章（4px 身份色边框 + 身份色图标）+ 10 间距 + 24 高轨道
  （`PaperAlt` 底 + 3px 墨边 + 身份色填充；手雷阈值红线照旧）+ 右侧读数列（display 字体 36，
  移动端 clamp 38，墨色字）。
- 战斗 HUD 底部**不再显示按键提示**（原独立细黑条已移除）：三卡下方保持干净，避免游玩画面被一排
  小字压住；键鼠 / 触控键位改由暂停菜单右栏「操作说明」卡承载（1100 宽双栏，键帽 + 动作）。
- 旧场景节点 `BottomStatusPanel / ComicBubble / PanelDivider` 只留作不可见容器（禁绘制、禁射线），
  `ControlsHintText / KeyHintStrip` 若存在也整体隐藏；`HealthBarBg / HealthBarFill` 绑定节点不得删除。
- 面板与卡区根节点都用**底边锚定**（anchor/pivot `(0.5, 0)`），由
  `HudController.ApplyBottomPanelLayout()` + `HudSpecialGaugeFactory.ApplyStatusCardsLayout()` 统一写几何；
  禁止各写一套 anchoredPosition（会错位）。
- 横向进度条一律 `Image.Type.Filled + Horizontal`，精灵用 `UIFlatSprite.White`（1×1 白图）。
  内置九宫格 `UISprite` 在小高度下会露圆角、边缘发灰，禁止使用；`sprite == null` 会让 fillAmount 失效。
- 满能/低血只做**硬切**：不做旋转虚线环 / 放射爆闪 / 呼吸缩放。
- 手雷耗墨刻度在横向条上是**竖线**（2px 墨底 + 3px 红线），位置 = `bombInkCost / maxInk`；
  手雷与墨水脱钩（`bombInkCost = 0`）时自动隐藏。
- 手雷冷却只在**准星下方**显示一条 `BOMB ███░░ 5.4s` 徽标（冷却结束短促 READY）；
  移动端同时把手雷按钮标签切成倒计时秒数。

## 首页（Ready 主菜单）与武器整备（P14-I）

手机屏幕物理尺寸只有显示器的零头，**不能只把字号 ×1.28、盒子保持桌面尺寸**——那样一定"一看就很小"。
首页与武器栏的所有盒子/字号统一来自 `Scripts/UI/MenuLayoutMath.cs`（桌面 / 移动端两套数，EditMode 可断言）。

### 版式（t-1 新野兽派 · 波次3a）

深色舞台 + **左侧 Hero 大卡 + 右侧 2×2 次级卡**，卡片区横向 ≥85% 屏宽，禁止中部空场。
所有盒子来自 `MenuLayoutMath.Home()` 的 `HeroCard / Tile(i) / HeroCta / FooterTag / VersionTag`，
`MenuLayoutMathTests` 断言"不出画布 / 互不重叠 / 横向铺满"。

| Hero 大卡 | 728 宽 | 940 宽 | 主行动黄实底 + 4px 墨框 + **Hero 硬影 (6,-7)**，左上「PLAY」黑底白字角签 |

| 顶部小按钮 | 不显示 | 300×96 | 右上「自定义按键」：纸白底 + 3px 墨框 + 按钮硬影 |

- **卡内信息密度**：Hero 卡与次级卡都要有 `·` 分隔的密集信息行（模式/时长/场地、战绩、键位），
  不允许"只有标题 + 大片空白"；信息卡不放 `》` 箭头（箭头 = 可点）。
- **整卡可点**：次级卡把按钮铺满整张卡（透明 Image 只负责射线），按下阴影归零 + 内容位移。

- 首页内容必须放在 `MenuSafeArea`（`SafeAreaFitter`）里，背景装饰留在全屏层；刘海/圆角不吃字。
- 抽屉收起时显示左下「武器整备」整备卡（替代过去 176×72 的纯黄方块页签），选枪后实时刷新图标与名称。
- 武器卡编号方块 `[1]~[7]` **只在桌面显示**（手机没有数字键）。
- 移动端属性串要压缩（`10.0/s → 10/s`、去掉「(架枪15/s)」），避免 759px 卡面溢出。
- **TMP 禁在紧凑盒子里用 `Truncate`**：它会按行高做纵向截断（34px 框放 28 号字 → 整段字符被丢掉，
  `textInfo.characterCount = 0`，看起来就是"文字没渲染"）。统一 `Overflow + NoWrap`，宽度交给版面表控制。
- `MatchFlowUI` 的 `uiTheme` 在场景里可能是空引用 → 首页字体落到 TMP 全局 fallback。
  `EnsureTheme()`（运行时资源库 → 编辑器 AssetDatabase）必须跑在 `EnsureReadyVisuals` 之前。

### 信息浮层（战绩 / 键位说明）

「战绩」「键位说明 / 操作指南」两张次级卡是可点卡（带 `》`），点击打开详情浮层
（`Scripts/UI/HomeInfoOverlay.cs`，度量在 `HomeInfoLayoutMath`，内容在 `HomeInfoContent`）：

- 浮层跑在**独立 Overlay Canvas（sortingOrder 50）**上：必须高于武器抽屉（15）与 HUD（10），
  否则左下「武器整备」卡会浮在遮罩之上还能被点开。
- 浮层打开时首页开赛快捷键（Space/Enter/R）、暂停菜单 Esc、武器抽屉 1~7/Esc 全部让路；
  `HomeInfoOverlay.TryCloseFromMenuInput()` 用「同帧已消费」标记保证一个 Esc 只关浮层，不会顺带打开暂停或抽屉。
- 键位表是 `HomeInfoContent.Controls(mobile)` 这一份数据源，暂停菜单「操作说明」卡与首页浮层共用，禁止再抄一份。

## 绝对禁止

- ❌ 渐变色 / 柔光 / 玻璃拟态
- ❌ **模糊阴影**：blur / spread / 半透明阴影 / 渐变投影 / 多层柔光（唯一允许的是零模糊硬偏移底板，见上）
- ❌ 半调网点 / 动作线 / 对话气泡尾巴（漫画语言，已废弃）
- ❌ 圆角矩形面板（圆角只允许出现在"正圆/胶囊"上）
- ❌ 墨滴 wobble 有机边缘
- ❌ 弹簧 / elastic / 无限呼吸 / 循环脉冲 / 摆动动画（功能性告警闪烁除外）
- ❌ 交互动画 >100ms（入场 pop-in 与松开回弹除外：入场 0.22s、回弹 0.1s）
- ❌ 低对比配色：正文对比度必须 ≥ 4.5（`ComicStyle.ContrastRatio` 自检）
- ❌ 移动端字号 < 桌面字号；正文 < 18（移动端 < 20）；**任何可读文字 13~16px**
- ❌ 触控层用 5 色实底（改为墨黑半透明底 + 功能色 4px 描边 + 功能色图标）
- ❌ 对称居中堆叠的"常规后台"布局（标题+列表居中排列）：用色块错位、超大字、左右分栏制造张力
- ❌ 旧 API `UnityEngine.Input.GetKeyDown`（项目只启用新 Input System）

## 屏幕特效例外（镜头层）

**不是 UI 面板、而是屏幕/镜头反馈**的图层可以打破上面的「纯色直角」规则：

- `UI/InkEdgeWarningView`（P18-A 踩敌墨全屏边缘墨迹）：对齐 INKWAVE `src/fx/screenfx.js` 的 edgeInk，
  允许**有机噪声抖动边界、湿润高光、顶部垂滴**，颜色用敌方队色；
- 该层由 `HudController` 自动装配到 HUD 画布 `sibling 0`（盖住 3D、位于所有 HUD 控件之下），
  不在 SafeArea 内；空闲时整块 Graphic 关闭，效果期间只多 1 个 DrawCall；
- 例外仅限这一层。菜单、按钮、面板、HUD 读数、进度条仍然必须遵守纯色直角、无渐变、无 wobble。

## 形状基元（`UIInkShapeGraphic`）

| Shape | 用途 |
|---|---|
| `SharpRect`（新增） | 直角矩形：面板、按钮、色块 |
| `Pill`（新增） | 全圆角胶囊：Tag、状态徽章 |
| `Blob` | 仅作**正圆/椭圆**用（wobble 已归零）：头像、装饰圆 |
| `RoundedRect` | 兼容保留，新界面请用 `SharpRect` |
| `SpeechBubble` | 兼容保留，新界面禁用 |

快捷入口：`ApplyComic(fill)` 现在是几何风默认（直角、无网点、无边光、**默认无硬影**）。
要硬影不要靠它——用 `theme.ApplyHardShadow(graphic, level)` 显式开档，保证偏移只有规范里的那几档。

## 交付自检清单

- [ ] 渐变 / 网点 / 气泡尾 / wobble 全无（唯一例外：`InkEdgeWarningView` 屏幕边缘敌墨反馈）
- [ ] **阴影是否有 blur / spread / 半透明**：硬影必须是同形状、纯色、不透明、零模糊的偏移底板
- [ ] 硬影偏移是否只用了档位表里的值（按钮 3,-4 / 悬停 5,-6 / 面板 4,-5 / Hero 6,-7 / 弹窗 8,-9 / 色签 2,-3）
- [ ] **是否存在 13~16px 的可读文字**（HUD 标签 18~20、读数 28~32、比分 44、计时器 72~76、CTA 46、Hero 120）
- [ ] **触控层是否 5 色实底**（应为墨黑半透明底 + 功能色 4px 描边 + 功能色图标）
- [ ] **图标显示尺寸是否 <24px**（小于 24 直接隐藏，避免糊成噪点）
- [ ] 整页菜单/结算是否用深色舞台底；战斗 HUD 是否仍保持透明浮层（不做整底）
- [ ] 卡片是否「纸白 + 3px 墨框 + 硬影 + 5px 身份色带」，而不是整面亮色
- [ ] 单屏高饱和功能色 ≤ 4 种；主行动黄与“奖励金”是同一色，没有第二种黄
- [ ] 进度条 = 纯色直角 + `UIFlatSprite.White`，无圆角 / 渐变 / 两端尖角
- [ ] 底部仪表全部横向、落在血条正上方且不伸进左右触控区

- [ ] 紧凑文字没有被 TMP `Truncate` 纵向截断（看不到字就是它）
- [ ] 面板直角或全圆，无中间圆角
- [ ] 按压是 **0ms 硬切 + 0.1s Cubic-Out 回弹**，没有弹簧过冲；入场 pop-in 0.05s/张错峰
- [ ] 移动端字号 ≥ 桌面，正文 ≥ 18（移动端 ≥20），全部走 `UITypography.Font()`
- [ ] 正文对比度 ≥ 4.5
- [ ] 图标缺失时隐藏而非白块
- [ ] 游戏触控键 ≥ 132 UI px @1920×1080；设置/编辑器按钮高 ≥64px、字号 ≥20
- [ ] 编译干净 + `tools/run_tests.sh ui` 全绿
